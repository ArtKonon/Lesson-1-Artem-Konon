Як запустити програму Greet?

- перейдіть в папку greet за шляхом Lesson-1-Artem-Konon/cmd/greet
- напишіть в терміналі go run main.go та за бажанням ваше імʼя. 
    Наприклад: go run main.go Alex
    Відповідь: Hello, Alex! Welcome to Go.
- натисніть enter/return та прочитайте відповідь в терміналі 


Як запустити програму Converter?

- перейдіть в папку converter за шляхом Lesson-1-Artem-Konon/cmd/converter
- для конвертації валюти напишіть в терміналі go run main.go та вкажіть суму й обмінний курс. 
    Наприклад: go run main.go 1000 45.2 (обовʼязково крапка (.), а не кома (,))
    Відповідь: 1000.00 = 45000.00
- натисніть enter/return та прочитайте відповідь в терміналі
